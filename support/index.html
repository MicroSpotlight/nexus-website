Support技术支持

Start with the checks below. If Nexus still misbehaves, open a focused issue with the smallest useful reproduction.先按照下面的排查步骤操作。如果 Nexus 仍然异常，请带上最小可复现信息提交 Issue。

What does Nexus provide?Nexus 提供什么？

Nexus is a player and library client. It does not include a content catalog or a source list. Add only files, endpoints, and servers you are authorized to access.Nexus 是播放器和片库客户端，不内置内容片库或来源列表。请只添加你有权访问的文件、接口和服务器。

My source does not connect.来源无法连接怎么办？

  1. Confirm the device can reach the endpoint in the same network and that the server is running.确认设备可以在同一网络访问接口，且服务器正在运行。
  2. Check the scheme, port, path, and authentication details. Re-enter passwords instead of exporting them.检查协议、端口、路径和鉴权信息。不要导出密码，重新输入更安全。
  3. Use Source Management → Test Connection and follow the redacted recovery guidance.进入“来源管理 → 测试连接”，按照脱敏后的恢复建议操作。

Playback or subtitles are wrong.播放或字幕显示异常怎么办？

Open the player settings and try the other playback engine, a different video scale, or another audio/subtitle track. For ASS/SSA, include the subtitle format, the affected tag family, and whether the issue occurs after pause/seek. Do not attach copyrighted media or private source URLs.打开播放器设置，尝试另一个播放引擎、不同画面比例或其他音轨/字幕轨。ASS/SSA 问题请提供字幕格式、受影响的标签类型，以及暂停/拖动后是否复现。不要上传受版权保护的媒体或私有来源 URL。

Where are my files and credentials?文件和凭据保存在哪里？

Library records, preferences, history, favorites, and downloads are local by default. Source passwords are stored through Apple Keychain. Optional CloudKit sync is controlled from Privacy & Data and does not include source addresses or credentials.片库记录、偏好、记录、收藏和下载默认保存在本机。来源密码通过 Apple 钥匙串保存。可选 CloudKit 同步可在“隐私与数据”中管理，不包含来源地址或凭据。

What should I include in a bug report?提交问题时应包含什么？

  • Nexus version and iOS/iPadOS version.Nexus 版本和 iOS/iPadOS 版本。
  • Device model and whether the issue is reproducible in a clean local file.设备型号，以及在本地测试文件中是否可以复现。
  • The source type and operation (browse, search, play, download), but never the source URL, username, password, token, cookie, or private media.来源类型和操作（浏览、搜索、播放、下载），但不要提供来源 URL、用户名、密码、Token、Cookie 或私有媒体。
  • A short sequence of steps, the expected result, the actual result, and a redacted screenshot if useful.简短复现步骤、预期结果、实际结果，以及必要时的脱敏截图。

Open GitHub support打开 GitHub 支持
